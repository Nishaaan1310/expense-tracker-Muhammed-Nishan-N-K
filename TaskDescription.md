Building an Expense Tracker App

To build a simple Expense Tracker web application using HTML, CSS, and JavaScript.

# Objective
Create an Expense Tracker application where users can:
Add an income or expense transaction.
Enter the amount, category, date, and description.
Edit and delete transactions.
View total income, total expenses, and current balance.
Filter transactions by income, expense, or category.
Save the data using browser Local Storage, so it remains available after refreshing the page.
View the application properly on desktop and mobile screens.

# Optional Bonus

Add a monthly expense summary.
Display a simple category-wise expense chart.
Add validation and helpful error messages.
