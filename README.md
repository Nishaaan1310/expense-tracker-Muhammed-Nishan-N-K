
## Run the Application

Launch the live project by visiting the [Expense Tracker](https://nishaaan1310.github.io/expense-tracker-Muhammed-Nishan-N-K/).

A simple Expense Tracker web application using HTML, CSS, and JavaScript.

features include:
1) Add an income or expense transaction.
2) Edit and delete transactions
3) View total income, total expenses, and current balance
4) Filter transactions by income, expense, or category.
5) Yearly expense summary.
6) A simple category-wise expense chart
